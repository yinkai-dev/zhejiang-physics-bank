# yinkai 的浙江高考物理题库

面向浙江物理选考备考的静态题库：按备考年份、首考／二考、试卷和主题找原题，查看已有原卷答案，组成练习并打印。

公开仓库：[yinkai-dev/zhejiang-physics-bank](https://github.com/yinkai-dev/zhejiang-physics-bank)。

首版使用已经整理的 **2025 二考、2026 二考、2027 首考** 三个题库，共 **37 卷、666 题**。这些是模拟、联考及诊断等备考试卷；后续逐步补充历年正式真题。原分类中的年份表示备考届别，实际考试年月另存。

技术路线：本机整理和构建，GitHub 管理代码及可公开的静态产物，GitHub Pages 托管网页。首版不需要在线数据库或业务服务器。浏览器完成筛选、单题展示、练习清单和打印。

本机原始题包、审核材料与导入证据保存在 Git 忽略的 `.local/`。后续通过字段白名单导出网页所需题面、图片和答案；原始题包整目录不作为站点发布目录。仅克隆当前仓库尚不能生成真实题库，需要另行提供本机数据快照。

参考项目：[Wasio 物理竞赛题库](https://github.com/wasio-official/wasio-official.github.io)。借鉴其静态数据组织和考点导航；网站界面独立实现。
