# 界面约定

原生 TypeScript 多页网站，无 Tailwind 或组件库。采用浅色阅读界面，字体跟随系统；题文使用衬线字，导航使用无衬线字。

主内容是原题、卷名和题号，次级是备考分类和真实年月，统计与状态作为辅助。主操作：首页搜索、练习页打印；其余选题、切题、调序使用次级按钮或文字按钮。

颜色由 refactoring-ui 调色工具生成：青绿色主色、暖灰中性色。组件引用 `tokens.css` 的语义变量。正文、辅助文字、主色文字共三类；字重仅 400/600。字号使用 12/14/16/18/20/24/30/36/48，间距以 4/8/12/16/24/32/48/64 为主。组间距大于组内距。

圆角：控件 6px、内容面板 8px；边线 1px，重点分隔 2px。页面以边线分组，悬停时只加一级阴影。按钮不靠颜色单独传递状态，保留文字与选中标记。10 组实际文字配色均通过 4.5:1 对比度校验。

没有 Tailwind，因此 `theme.css` 仅记录主题入口，不引入 Tailwind 依赖。新增视觉值应先加入 token 或明确的布局用途。
