# 数据与标签规范

本文件定义题库静态导出、元数据结构、答案分层与筛选检索的正式合同。`metadata/paper-catalog.json` 保存可公开的集合与逐卷元数据；导出器（`scripts/export-bank.mjs`）和校验器（`scripts/check-public.mjs`）按本规范执行确定性白名单投影。

## 1. 六库结构、年份与考试分类

题库采用**独立历年选考真题集合 + 五个备考集合**的六库结构，**备考目标年份与实际考试年份分开存储和筛选**：

| 集合 ID (`collection_id`) | 中文名称 | 试卷性质 (`exam_kind`) | 说明 |
| --- | --- | --- | --- |
| `zj-zhenti` | 历年选考真题 | `official` | 2015 年 10 月至 2026 年 6 月全部 22 个浙江物理选考官方考次；`target_year` 与 `target_session` 为 `null` |
| `zj-27-shoukao` | 2027 首考 | `practice` | 面向 2027 首考的模拟／联考／诊断卷 |
| `zj-26-erkao` | 2026 二考 | `practice` | 面向 2026 二考的模拟／联考／诊断卷 |
| `zj-26-shoukao` | 2026 首考 | `practice` | 面向 2026 首考的模拟／联考／诊断卷 |
| `zj-25-erkao` | 2025 二考 | `practice` | 面向 2025 二考的模拟／联考／诊断卷 |
| `zj-25-shoukao` | 2025 首考 | `practice` | 面向 2025 首考的模拟／联考／诊断卷 |

逐卷核心字段定义：

| 字段 | 含义与规则 |
| --- | --- |
| `paper_id` | 稳定卷 ID，采用 `collection_id--source_document_id`，改标题不改 ID |
| `collection_id` | 所属集合 ID（见上表）；新增集合由目录驱动，不硬编码在前端源码中 |
| `original_classification` | 原有中文分类（如 `2027 首考`、`历年选考真题`） |
| `target_year` | 备考卷面向的选考届别（如 `2027`）；正式真题为 `null` |
| `target_session` | 备考卷面向的阶段：首考 `first`、二考 `second`；正式真题为 `null` |
| `exam_year` / `exam_month` | 试卷实际考试年／月；未知为 `null` |
| `exam_date` | 仅有原卷明确完整日期时填写 `YYYY-MM-DD`；不从年月补成 1 日 |
| `date_basis` | 日期证据来源（如 `source_title_yymm` 表示从卷名 YYMM 推得，真题按官方考次显式标注） |
| `exam_kind` | `practice`（备考卷）或 `official`（正式真题） |
| `official_session` | 正式真题的实际考次：`first`（1 月／4 月／6 月前上半场或首考）或 `second`（6 月／10 月／11 月等对应官方考次）；备考卷为 `null` |
| `title` | 原卷标题，保留城市、学校、联盟与考试名称 |
| `metadata_review_status` | 元数据核验状态（如 `classification_preserved_date_inferred`） |

备考卷示例：

```json
{
  "paper_id": "zj-27-shoukao--z20-lianmeng-2608",
  "collection_id": "zj-27-shoukao",
  "title": "物理卷-2608Z20联盟",
  "original_classification": "2027 首考",
  "target_year": 2027,
  "target_session": "first",
  "exam_year": 2026,
  "exam_month": 8,
  "exam_date": null,
  "date_basis": "source_title_yymm",
  "exam_kind": "practice",
  "official_session": null
}
```

- 界面同时展示备考归属与实际考试年月（例如“2027 首考备考 · 2026 年 8 月 · Z20 联盟”）。“2027 首考”筛选命中该卷；“实际考试年份 2027”不命中。
- 正式真题统一归入独立集合 `zj-zhenti`，按实际 `exam_year`、`exam_month` 与 `official_session` 建档，`exam_kind="official"` 必须显式填写，禁止静默降级为 `practice`。

## 2. 筛选与检索规则

- **维度组合**：不同筛选维度取交集；同一维度多选取并集。界面明确区分“备考年份”与“实际考试年份”。
- **动态派生**：所有集合、年份、卷数和题数选项均从 `public/data/catalog.json` 动态生成，前端、测试和 PDF 服务均不写死总卷数或总题数。
- **五大主题与题型**：沿用来源标签（力学、电学、光学、热学、近代物理；单选、多选、实验、计算等）。一题多主题时按稳定题目 ID 去重，不得把标签计数相加当作总题数。
- **URL 同步与完整计数**：所有筛选、搜索、排序与页码写入 URL，刷新与分享可精确复现；空结果明确提示，不自动放宽条件；轻索引全量计算命中总数后分页渲染。

## 3. 题面、答案分层与静态投影

本机 `.local/banks/` 中的冻结 `question-package`（`questions.jsonl`、资产清单、配图、标签与答案包）保持只读。导出器仅按显式白名单投影展示所需字段到 `public/data/` 与 `public/images/`：

| 数据 | 导出与校验要求 |
| --- | --- |
| 题目 ID | 全局唯一组合 `collection_id--question_id`，保留原 ID 与字符串原题号 |
| 卷关系 | 绑定稳定 `paper_id`，继承卷级年份和考试分类，避免元数据漂移 |
| 题干／选项 | 按受控块 schema 处理 `text` / `math` / `figure` / `table` / `score`；题文不作为任意 HTML 执行 |
| 配图 | 仅复制被题干、选项、原卷答案或 AI 参考答案实际引用的 PNG，按 SHA256 命名并校验尺寸与魔数 |
| 公式 | 保留标准闭式白名单 LaTeX，通过 MathJax 3.2.2 全量渲染检查（0 错误） |
| 来源与指纹 | 展示原卷名称、原题号与公开来源指纹（`fingerprint`），剥离本机绝对路径、审核日志与运维身份 |
| 原卷答案 (`answer_status`) | 严格按题目指纹绑定，区分三种状态：`source`（原卷来源答案，有详解时选择题 `key` 与 `body`、非选择题答案与详解一并展示）、`missing`（原卷明确缺失答案）、`not_ingested`（历史尚未接入答案包占位，当前全站已清零） |
| AI 参考答案 (`ai_reference`) | 仅允许附加在 `answer_status === "missing"` 的题目上，作为独立折叠层展示；必须通过 `scripts/lib/ai-reference.mjs` 校验，绑定 `question_sha256` 与 `review_sha256`，并在 `label` 中显式注明模型来源与“未教师复核”，严禁冒充原卷来源答案 |

公开静态产物固定为：

- `public/data/catalog.json`：集合统计、逐卷元数据与公开数据版本哈希（`public_version`）
- `public/data/questions-index.json`：全量轻量检索索引
- `public/data/papers/<paper_id>.json`：逐卷完整题面与答案详情
- `public/images/<sha256>.png`：全站实际引用的题图与解答图

## 4. 完整性门禁与变更保护

- **三方数量一致**：`metadata/paper-catalog.json`、本机活动 `release` 与导出后的 `public/data/` 在卷数、题数、答案状态计数上必须完全一致；导出结果与引用图片文件集合一一对应（无孤立图、无缺图）。
- **已上线题目保护**：常规导出和发布仅允许新增题目、为 `not_ingested` 题目补齐 `source` 答案，禁止静默移除或改动已上线题目的题面与指纹；触发变更时自动中止并列出受影响题号，须经负责人确认后显式加 `--allow-change` 放行。
- **不固定题数模板**：数据模型与导出器支持任意题数与题型分布（如 18 题、19 题、20 题、22 题选考真题），不依赖固定题号区间。
- **工程验证与教师复核分离**：数据导出、公式检查、像素核验与 PDF 排版测试均属工程与转录核验，不替代教师物理复核；新增题目的分类与转录按规范注明“AI 分类／转录核验，未教师复核”。

## 5. 后续扩展（独立注释层）

原题包字段严格受限且带哈希校验，后续新增标注均不写回只读原包，而以独立注释层按 `question_id + fingerprint + annotation_version` 绑定并在静态导出时合并：

- **细分考点**：受控词表、稳定 ID、一题多标签，区分主考点、辅助考点、方法与物理情境。
- **难度与作答统计**：基础／中档／较难三档及判定依据，区分 AI 预估、教师审定与真实学生正确率。
- **推理节点与错因诊断**：参见 [错题诊断与自适应推荐调研](错题诊断与自适应推荐调研.md)。

## 6. 本机与公开边界

- `.local/banks/`、`.local/evidence/`、本机配置文件（`.local/publish-config.json`、`.local/ingest-config.json`）与原始 PDF／Word 源件均由 Git 忽略，仅留在本机。
- 公开仓库仅提交源码、`metadata/paper-catalog.json`、经白名单校验的 `public/data/` 与 `public/images/` 及公开文档；GitHub Actions 仅凭公开仓库即可独立完成校验、构建与 Pages 部署。
