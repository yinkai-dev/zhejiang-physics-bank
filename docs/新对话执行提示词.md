将下面整段复制到以本项目文件夹为工作目录的新对话中。它用于下一轮执行；本轮只完成了文档、数据准备和仓库初始化。

请在当前项目“yinkai 的浙江高考物理题库”中，依据 AGENTS.md、README.md、docs/实施方案.md、docs/数据与标签规范.md、docs/执行计划.md 实现首版静态网站，并完成 GitHub Pages 发布和实际验证。

先检查 Git 状态，保留已有改动。读取 `.local/接手补充.md` 定位已准备的数据；原始三库快照已经在本项目 `.local/banks/`，不必去生产服务器重新导出，也不需要重新 OCR 已有题包。

产品目标：用现有浙江三库做出按年份、考试阶段、试卷、题型和主题找题的公开静态题库，可以查看原题及已有答案，跨卷选题并打印。首版全量范围是 2025 二考11卷198题、2026二考21卷378题、2027首考5卷90题，共37卷666题。这些是备考模拟／联考／诊断等卷，不能写成全部为高考正式真题。新增真题候选、细分考点、难度评分放到后续。

年份非常重要：保留用户已有的“25二考／26二考／27首考”分类，使用 target_year 和 target_session 作为主要筛选，另存实际 exam_year／exam_month。2027首考库有实际2026年8—9月的卷，不能把它们误写成2027年举行的考试。现有逐卷元数据在 metadata/paper-catalog.json；推断日期有明确依据标记，未知日保留空值。

按 P1→P6 推进：先一卷验证导出和渲染，再完成三库全量、筛选、练习清单、打印、生产构建和 Pages 部署。一卷样板是中间结果，不是整个任务完成。

网站采用纯静态路线，优先 Vite + TypeScript。公式资源随网站部署；索引和逐卷详情分开，图片按需加载。代码和可公开的导出物放在本项目公开仓库，网页部署 GitHub Pages。当前阶段不增加在线数据库、账号会员、实时OCR、在线模型或自建服务器。

来源题包保持只读；通过字段白名单导出原题和已有原卷答案，保留稳定ID、原题号、图表关系和来源。463条有来源答案应正确关联；5条明确缺失、198条尚未接入答案包要如实显示，不自动编造解析。保留旧数据来源证据，新增分类和难度放在独立注释层。

公开范围是本项目代码及上述三库的网页展示所需题面、必要图片和已有答案。源包整目录、原始PDF、审核日志、凭据、本机路径和其他题库留在本地。检查通过后将允许发布的导出物加入Git，使 Actions 可单独从仓库构建；不要依赖本机私有目录来完成云端构建。

持续完成已经授权的开发、修复、提交、推送和首次 Pages 发布，不为常规可逆实现选择反复请求确认。遇到确实缺少的来源或权限，说明具体阻塞并继续不受影响的工作。不得将关键资源404、缺图或漏题隐藏为“正常完成”。

验证覆盖：全量数量及ID、年份交叉条件、筛选交集与去重、全部资源引用和答案关联；浏览器抽查手机布局、长公式、表格、多图；真实跨库打印；Pages子路径与线上深链接。既有未变化的源内容审核可复用，工程通过不等于教师物理审核或教学效果验证。
