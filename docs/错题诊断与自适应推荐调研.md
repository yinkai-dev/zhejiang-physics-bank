# 错题诊断与自适应推荐调研

调研日期：2026-11-11。本文记录研究与设计建议，不表示已实现推荐、完成教师审核或验证学习效果。

## 1. 判断与当前边界

建议把任务定义为：**根据学生在一道题中的具体困难，选出下一道最有教学价值的题，并用后续作答更新判断。** 题目相似度只是其中一个信号。

标签数量有限并非根本问题；更关键的是，同一题涉及多个推理动作，同一道错题也可能由不同原因造成。固定标签可以继续承担筛选和统计，开放文本、语义向量及结构化步骤承担更细的匹配。尚未确认的错因应保留为假设。

推荐关系还具有方向性：综合题中暴露某个困难后，下一题可能应退回一个隔离该能力的短题；反过来，从短题跳到综合题则需要额外的前置能力证据。因此，对称的题目相似度不能单独承担教学顺序的选择。有限的基础概念、条件与推理动作可以组合使用，不必预先穷举所有题型组合。

当前仓库有 666 题、463 条来源答案。本轮对公开 JSON 的只读字段统计显示，其中 258 条 `answer.body` 为空，只有答案 key；205 条有答案内容块。**内容块非空也不等于存在完整、可结构化的详解**，这些数字是工程字段检查，不是教师审核结果。现有题型、主题、题面和答案块不能直接充当经过审核的解法图；本轮也未发现已经准备好的学生作答轨迹。因此不能从现有数据直接训练可靠的个人掌握度模型。依据：[README](../README.md)、[数据与标签规范](数据与标签规范.md)、[现有类型](../src/types.ts)。

## 3. 解题步骤该如何拆

建议先做“可检索的推理节点”，再按需要连成图。以下是本项目的设计建议，不是上述论文提供的现成物理题 schema。

每个节点至少保留：

- **上下文**：对象／系统、研究过程、已知量、所求量，以及必要题图引用。
- **推理动作**：例如选择研究系统、判断某过程动量是否守恒、沿某轴列牛顿第二定律、建立图像与物理量的关系。
- **适用条件与依据**：为什么可以用该规律；所用前提来自题干哪一句或图中的什么信息。
- **输入、输出与依赖**：该步使用哪些已知或先前结论，得到什么中间量；允许哪些等价表达和替代解法。
- **常见错误与证据**：学生实际写了什么、可能违反哪个条件；分别保存观察与错因假设。
- **来源与审核状态**：原卷解析、教师补充或模型生成；后两者单独标注，不能覆盖原始来源答案。

例如“系统选择 → 判断碰撞阶段动量守恒 → 建立速度关系 → 转入碰撞后过程”比“第 1 句、第 2 句、第 3 句”更适合检索。只提取公式仍然不足：相同公式可能对应不同物理过程，而同一物理能力也可能通过不同方程表达。

检索节点时必须带回完整题目和前提。否则一个包含“能量守恒”的孤立句子，可能掩盖摩擦、外力做功或研究系统变化，导致推荐理由错误。

## 4. 从错题到下一题的流程

1. **收集可观察证据**：原题、学生答案／草稿／关键步骤、哪里开始不确定；必要时只追问一个能区分错因的问题。只有“做错了”时，先给低确定性的候选解释。
2. **形成若干错因假设**：区分系统／过程建模、规律适用条件、物理量关系、图像理解、代数计算等；保留证据和不确定性。允许“尚无法判断”，不要用模型自报信心当作已校准概率。
3. **明确下一题的用途**：错因不清时选诊断题；前置能力不足时选补前置题；错因较清时选隔离目标能力的补救题；最后再选换情境的迁移题。
4. **混合召回与重排**：标签限制学段与范围，关键词及公式匹配保留精确信号，语义检索匹配开放描述；有步骤索引时检索相关推理节点。随后结合候选题的实际解法、学生前置能力与重复练习历史排序。
5. **展示可核查的推荐理由**：说明它练哪个环节、与原错题有什么关系，以及为什么适合现在做；不能只写“相似度很高”。
6. **根据后续作答更新判断**：同题再做对、同结构题做对、换情境迁移成功，分别记录，不能视为等价的掌握证据。

例：学生在斜面题中写错摩擦力，可以先用一问区分“正压力关系错误”和“沿斜面投影错误”。前一种可选隔离正压力判断的题；后一种可选受力投影题；能正确建模但算错时，直接推综合斜面大题未必划算。此处是示意案例，未对应本题库中已审核的诊断样本。

## 5. 适合当前小题库的最小验证

先选一个内容簇，人工确认几十道题的关键推理节点及少量替代解法，避免一次为全部 666 题构建复杂图谱。样本数量是试点建议，不能当作统计效力保证。

建立包含真实或教师审定作答的诊断案例，以相同候选集合比较：现有标签筛选、题面语义检索、加入关键步骤及错因的检索重排。先使用教师确认的错因测试检索，再用自动诊断接入测试，以区分诊断错误与选题错误；按原卷或题型变式分组划分样本，防止近重复题让结果虚高。

评估分三层：

- **诊断层**：错因证据是否成立；不确定时是否提出有效追问；是否容纳其他正确解法。
- **推荐层**：教师盲评前几道题是否针对目标困难、前置要求是否合适、有无可用答案。与简单基线比较，而不只汇报向量相似度。
- **学习层**：在练习时间相近的条件下比较后续未见过的迁移题和延迟测验表现。仅“推荐题做对了”或“用户觉得很准”不足以证明补救有效。

当前还应记录候选缺口：666 题可能没有覆盖某个具体错因的适当训练题。确无合适题时明确说明缺口，不能为满足推荐数量把主题相近的综合题包装成精准补救。先用可解释的检索和规则策略形成证据，再决定是否需要训练学生模型或更复杂的选题策略。
