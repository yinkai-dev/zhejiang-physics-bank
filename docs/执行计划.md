## P1：先验证一个完整样板

1. 使用 `.local/banks/active.json` 指向的本地快照；核对 `.local/import-report.json` 和实际文件是否匹配。
2. 选一套有原卷答案的卷（优先 2027 首考中的一套），阅读实际题包、标签和答案 schema，再确定静态 schema。
3. 实现白名单导出器。先支持真实存在的块类型、图片映射、表格、公式、选项及答案 key/body，保留来源 ID 和原题号。
4. 用 `metadata/paper-catalog.json` 提供卷级分类；首先验证 target_year=2027、exam_year=2026 的例子。
5. 生成导出报告：卷／题／图片数量、答案状态、源 release 与导出版本；问题定位到题。

完成条件：一卷全部题目的题文和引用资源可加载；不是只截取一题或用伪造内容做界面。关键图、公式、表格与源内容抽样对照。源包不可修改。

## P2：实现浏览与筛选

1. 初始化 Vite + TypeScript，提交依赖锁文件，公式渲染依赖随站点发布。
2. 实现首页、试卷页、单题页；统一站点 base 路径，所有 JSON／图片／脚本 URL 支持项目子路径。
3. 实现年份、首考／二考、备考卷／真题、题型、主题、答案状态筛选及搜索。提供真实总命中数、空结果状态和清除筛选。
4. 将筛选写入 URL，直接复制链接、刷新和前后导航都可复现。
5. 优先清楚展示试卷来源、年份、题号；支持手机宽度。用题库里的真实长题、图形选项、实验表格验证布局。

完成条件：页面操作使用实际数据；生产构建可在 `/zhejiang-physics-bank/` 路径预览；控制台无阻塞错误，关键资源无 404。

## P3：接入全量现有浙江题库

1. 导出三库全量，保持原题号集合。校验目录中的37卷和666题与每卷详情对应。
2. 全量检查所有图片引用和答案关联；区分 463 条 source、5 条明确 missing、198 条未入库。
3. 用清单验证目标年份与实际年份交叉：2027 首考包含实际 2026 年试卷；实际 2027 年应为空。
4. 确保五大主题为多标签并按题去重；跨维度筛选取交集，不能用 Top-K 搜索结果代表全部匹配。
5. 抽查至少覆盖三个库、四类题型和图表／长公式／多图；优先检查转换改动涉及的内容。

完成条件：计数和来源集合一致；全量资源引用检查通过，抽样目视问题已解决或明确列为阻塞。新真题候选不混入已可用数据。

## P4：选题与打印

1. 实现稳定题目引用的练习清单，支持跨卷、去重、移除、排序；刷新后恢复。
2. 更新题库时检测已选题不存在或来源版本变化，提示用户核对，不能静默替题。
3. 实现独立打印样式；含原卷／原题号，可只打印题目或附已有答案；缺答案给出明确说明。
4. 用含选择、实验、计算、必要题图的跨库组合实际打印／另存 PDF，检查题数、来源、公式、图表和分页。

完成条件：不丢题、不换题、不截断关键内容；打印结果可实际用于练习。首版不强求与原卷逐像素同版。

## P5：发布 GitHub Pages

1. 确认下一轮用户指令包含实施和发布；本文件提供流程，不把“已准备文档”当作“网站已上线”。
2. 只将验证过的静态导出目录加入 Git；检查待提交文件，排除 `.local/`、原始 PDF、绝对路径、凭据、日志和上游运维配置。保持 `.local/` 忽略规则。
3. Actions 只使用公开仓库内容构建，采用官方 Pages artifact/deploy 流程和最小所需权限，部署目录仅 `dist/`。
4. 复核 GitHub Pages 当前限制及构建包体积。启用本仓 Pages，核对实际返回的站点 URL；预期项目路径为 `https://yinkai-dev.github.io/zhejiang-physics-bank/`，目前该地址未验证上线。
5. 等待部署完成，实测首页、筛选链接、单题深链接、图片、公式及练习打印入口。

完成条件：真实线上资源和页面通过检查，记录提交 SHA、部署 URL、时间和验证范围。开发预览成功不替代 Pages 验证。当前线路正常也不等于所有国内用户网络稳定。

## P6：交付与范围控制

交付内容：可访问链接、使用说明、源数据规模与答案缺失口径、更新题库步骤、本机重建命令及已知问题。进度写在本文件，原始验证结果放 `.local/evidence/`；公开文档只保留可公开的概括。

建议用 1–2 周完成：P1 约 1–2 天，P2–P3 约 3–5 天，P4–P5 约 2–4 天，剩余时间修复真实问题。时间是估计，先定位数据转换问题再决定范围；不能靠略过题图或答案验证宣称提前完成。

首版后优先级：补答案 → 细分考点 → 难度标注 → 正式真题 → 根据使用反馈增加高级功能。
