## 日常维护与增量更新

新试卷入库与三端发布遵循统一流程（详见 [AGENTS.md](../AGENTS.md) 与 [README](../README.md)）：

1. 使用 `物理试卷入库` 技能完成 OCR／Word 解析、源页视觉审核、门禁校验与本机 release 构包激活。
2. 在 `main` 分支运行 `node scripts/publish.mjs status` 查看三端差异，`node scripts/publish.mjs run --dry-run` 预演计划，确认无误后执行 `node scripts/publish.mjs run` 一键完成 PDF 服务更新与 GitHub Pages 发布。
3. 发布前严守“已上线题目只增不改”门禁；确需修正已上线题面时须经负责人确认后显式使用 `--allow-change`。

## 下一阶段（v2 演进方向）

当前 v1 雏形已满足“找原题、看答案、组练习、出 XeLaTeX PDF”的核心闭环。后续按优先级推进：

1. **细分知识点体系与标注**：建立受控物理考点词表（稳定 ID、一题多标签、主考点／辅助考点分离），作为独立注释层在静态导出时合并，不改写只读原题包。
2. **难度分层与依据**：引入基础／中档／较难三档标注及判定依据，区分 AI 预估、教师审定与真实学生作答统计。
3. **教师逐题复核与勘误机制**：逐步对 AI 转录核验题面与 39 道 AI 参考答案做教师复核，并建立轻量勘误回流路径。
4. **错题诊断与自适应推荐试点**：按 [错题诊断与自适应推荐调研](错题诊断与自适应推荐调研.md) 路线，先选单个知识簇试点“可检索推理节点 + 错因诊断 + 定向补救选题”的最小闭环验证。
5. **体验与长期运维观测**：持续观察 PDF 服务长期运行、TLS 证书自动续期、国内网络访问速度及移动端长题阅读体验；按需评估新考季模拟卷／真题的常规增补。
